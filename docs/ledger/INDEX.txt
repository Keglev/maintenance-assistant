=====================================================================
WHAT THIS DIRECTORY IS, AND WHAT IT IS NOT
=====================================================================
THIS DIRECTORY IS NOT HANDED TO AI SESSIONS. The three files given to
every session are docs/PROJECT-PHASES.txt, docs/DECISIONS.txt and
docs/REFACTOR-STANDARDS.txt, and that has not changed. What changed is
that PROJECT-PHASES.txt no longer carries 3,807 lines of closed history
inside it — the closed blocks live here, and the file keeps a two-line
stub where each one was, plus the rows that are still open.

IT IS HISTORY, NOT A SESSION INPUT. Read it when a stub points here, or
when a citation in another file lands in a moved block (see FORWARDING).
Do not load it wholesale into a prompt: doing that recreates the problem
the rotation solved.

EVERY FILE HERE IS BYTE-IDENTICAL to the lines it was cut from. No
reflow, no whitespace fix, no line-ending change. The rotation commit
proves it with cmp against the base commit, 75f06ba, and anyone can
repeat that:

  git show 75f06ba:docs/PROJECT-PHASES.txt | sed -n '<A>,<B>p' \
    | cmp - docs/ledger/<FILE>

THE MEASURED TRIGGER: PROJECT-PHASES.txt had reached 5,349 lines and
340,453 bytes, of which 72% was closed — history that every session
read and no session could act on.

NAMES ARE SCREAMING per ADR-010 rule 1: these are records, not
explanatory prose, and they are immutable once written here. A
correction to a moved block is made where corrections are always made,
in the live record, and never by editing the file it was cut from.

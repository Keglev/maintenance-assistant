COLLAPSE_ABOVE
Type : number
Default value : 2

How many sources fit under an answer before the list starts hiding it.

Three or more is where the answer stops being the first thing on screen after a scroll on a tablet. Two is a pair of cards and no reason for a control.

DATES
Type : unknown
Default value : new DatePipe('en-US')
LOCALES
Type : Readonly<Record<UiLanguage, string>>
Default value : { de: 'de', en: 'en-US', }

Which locale Angular formats with. de is registered in app.config.ts; en-US is built in.
PATTERNS
Type : Readonly<Record<UiLanguage, string>>
Default value : { de: 'dd.MM.yyyy', en: 'MM/dd/yyyy', }

The date format each language actually expects.

Written out rather than left to 'shortDate', which gives dd.MM.yy in German — a two-digit year on a maintenance record is the one place ambiguity is not worth the four characters it saves. Both patterns are the everyday civil format of their language, not an ISO compromise neither side reads naturally.
